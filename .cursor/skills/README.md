# Cursor skills

Источник: [mattpocock/skills](https://github.com/mattpocock/skills) (MIT).

Для `/grill-with-docs` нужны все три:

- `grill-with-docs`
- `grilling`
- `domain-modeling`

Вызов: `/grill-with-docs` (через дефисы, не пробелы).

Дубликат для агентов: [`.agents/skills/`](../.agents/skills/).

На все локальные проекты: `npx skills add mattpocock/skills --skill grill-with-docs --skill grilling --skill domain-modeling` (ставит в `~/.cursor/skills`).
