# Astro AI

Домен натальных карт пользователя и их наложений на карты затмений.

## Language

**Пользователь**:
Авторизованный человек в приложении.
_Avoid_: Client (в UI), аккаунт

**Профиль**:
Данные пользователя: имя, email, дата/время/место рождения. Экран `/` («Мой профиль»).
_Avoid_: Предпочитаемые данные рождения

**Меню пользователя**:
Кнопка с именем в правом верхнем углу шапки. Пункты: Мой профиль, Мои карты, Выйти.
_Avoid_: Где Алёна (это просто отображаемое имя)

**Основная карта**:
Единственная натальная карта, построенная из ДР профиля; пометка primary. Показывается на экране профиля.
_Avoid_: Моя карта (разговорно ок, в модели — основная)

**Карта**:
Натальная карта по конкретным ДР/времени/месту; обычная, если не основная.
_Avoid_: Map, чарт в UI-копирайте

**Мои карты**:
Список всех карт пользователя (основная и обычные).
_Avoid_: История карт как отдельная сущность

**Добавить карту**:
Создание обычной (не основной) карты через отдельную форму без автоподстановки ДР профиля.

**Обновить описание**:
Повторная AI-интерпретация по уже сохранённым планетам/домам той же карты (`/reinterpret`). Не пересчёт Astrology API.

**Пересчитать**:
Если ДР профиля изменили относительно основной карты — полный новый расчёт (Astrology API + AI). Бывшая основная снимает пометку и остаётся в «Мои карты»; новая становится основной. Не удаление.
_Avoid_: путать с «Обновить описание»

**Затмение**:
Солнечное или лунное событие, заданное типом и моментом его максимума.

**Карта затмения**:
Положения небесных тел на момент максимума затмения, общие для всех пользователей.
_Avoid_: Натальная карта затмения

**Наложение**:
Сравнение конкретной натальной карты с картой выбранного затмения.
_Avoid_: Смешивать с отдельным аспектом

**Межкартный аспект**:
Угловая связь между телом натальной карты и телом карты затмения: соединение, секстиль, квадрат, трин или оппозиция.

**Орбис**:
Отклонение углового расстояния между телами от точного угла аспекта.

**Расшифровка наложения**:
Интерпретация найденных межкартных аспектов с учётом натальной карты и выбранного затмения.

**Наложения**:
Раздел с созданием сравнений карт и списком сохранённых результатов и чатов.
