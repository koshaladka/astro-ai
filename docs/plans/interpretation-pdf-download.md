# Скачивание расшифровки в PDF

Пользователь выбрал PDF как основной формат для чтения на телефоне. Заменить скачивание Markdown у натальной карты на PDF, добавить PDF к сохранённой расшифровке затмения. Сохранить заголовки, абзацы, списки, кириллицу; длинный текст переносить на страницы A4. Встроить лицензированный шрифт, без внешних сервисов и повторного запроса ИИ. Генерация локально в браузере, состояние подготовки и ошибка рядом с кнопкой. PDF содержит сохранённый текст и данные выбранной карты; переписка не включается.

Проверки: кириллица и многостраничный текст через извлечение текста из PDF, проверка типов, production build. Изменения — отдельная ветка и PR без merge/deploy. Проверка на физическом телефоне остаётся за пределами среды.

## Реализация и проверка

Кнопка «Скачать PDF» есть у натальной карты (включая основную) и расшифровки затмения. jsPDF загружается по нажатию, шрифты DejaVu Sans из `public/fonts` встраиваются в файл вместе с кириллицей. Лицензия шрифтов включена. Заголовки, абзацы, списки, переносы и номера страниц сохраняются, HTML из текста не исполняется. PDF собирается из сохранённых данных без сервера экспорта. Каталог `public` уже копируется в Docker runner.

Проверены: TypeScript, `git diff --check`; тестовый PDF на 7 страницах, извлечение кириллицы, знака градуса и последнего абзаца через pdftotext, визуальный просмотр первой страницы. Физический iPhone/Android не проверялся.

Production-сборка `npm run build` завершилась успешно.
