# Минимизация сессии, снимков и удаление чатов

Разрешено пользователем: реализовать три пункта, отдельный PR без merge/deploy.

Новые JWT содержат только userId и стандартные временные поля; старые подписанные токены принимаются до истечения срока, их email/name игнорируются. /auth/me читает актуальный профиль из БД.

Новые снимки наложений не содержат birthInput и дат в названии. Старые документы массово не переписываются; выдача также исключает birthInput и старые названия с датами. Расчёты и положения сохраняются без повторных запросов Astro API.

Удаление карты владельцем удаляет связанные наложения целиком, включая архивные чаты. Отдельная кнопка с подтверждением очищает чат карты или наложения, сохраняя расчёт и трактовку. Очистка наложения охватывает архивы. Конкурирующий AI-ответ не должен восстановить удалённый чат. Чужие и бесхозные карты недоступны.

Старые записи и профиль не очищаются автоматически. Это минимизация, не освобождение от 152-ФЗ. Очистка резервных копий/логов и аккаунта целиком — вне этой задачи.

## Реализованное поведение и совместимость

- Метка наложения теперь «Карта · последние 6 символов ID», без даты, времени и места. Для старых документов такая метка формируется при выдаче, без миграции БД.
- DELETE /api/charts/:id/chat очищает только переписку карты; DELETE /api/overlays/:id/chat — текущую и архивную переписку этого наложения. Оба требуют владельца. Кнопки подтверждают действие. Чаты отдельных наложений удаляются отдельно от чата натальной карты.
- Активный AI-запрос наложения блокирует очистку с ответом 409. Для натального чата счётчик версии не позволяет завершившемуся старому запросу снова сохранить сообщения.
- Удаление карты сначала помечает её недоступной, затем удаляет наложения, результат, запрос и клиента. На standalone MongoDB это не общая транзакция: при ошибке операцию можно повторить. Проверка после создания наложения предотвращает сохранение сироты при конкурентном удалении карты.
- birthPreferences профиля, старые JWT на устройствах и старые снимки в БД не очищаются автоматически. Старые JWT сохраняют срок действия до 7 дней, но их контактные поля больше не используются. Настоящее удаление карты удаляет связанные с ней снимки и архивы.
- PR №16 отдельно минимизирует контексты ИИ и диагностику. Эта задача дополняет его; ни один PR не разворачивается автоматически в рамках работы.

Проверки: Node.js 24, `node --experimental-strip-types tests/storage-minimization.test.mjs` (9 тестов с подменой БД/JWT/AI) и `node --experimental-strip-types tests/eclipse-luminary.test.mjs` (8 тестов расчётов/промпта). Полная сборка и интеграция с реальной MongoDB не запускались.
