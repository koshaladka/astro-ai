# Минимизация данных

Структурированный контекст ИИ строится явными проекциями: положения планет, дома, аспекты и необходимые сведения о затмении. Исходные дата/время/место рождения, названия карт и идентификаторы записей не добавляются. Для обсуждения сохраняются вопрос, история и готовая трактовка.

Astrology API получает необходимые для расчёта дату, время, координаты, часовой пояс и конфигурацию. Лишние поля объекта, включая email и идентификаторы аккаунта, исключаются. Запросы AI-провайдерам содержат модель и сообщения, без идентификаторов аккаунта приложения.

API_LOG выключен по умолчанию. При включении приложение записывает только разрешённое имя операции, HTTP-метод/статус, длительность и случайный ID вызова. Тела, заголовки, URL, параметры адреса и тексты ошибок не читаются для логирования. Langfuse получает только имя операции, случайный ID, длительность и успех. Его сбой не меняет результат вызова ИИ; ожидание ограничено одной секундой.

## Ограничения

Это минимизация, а не полная анонимизация. В БД остаются email, данные рождения, карты и переписка. Пользовательский вопрос, история и сохранённая трактовка могут содержать личные сведения; свободный текст передаётся ИИ как есть. По астрологическим положениям возможно восстановление части исходных данных. Astrology API продолжает получать данные рождения.

Изменение не удаляет старые логи и traces, не меняет настройки журналов reverse proxy/хостинга и не гарантирует отсутствие хранения у внешних провайдеров. Юридическое оформление, локализация, сроки хранения и удаление данных требуют отдельных решений.

## Проверки

Без установки зависимостей, Node.js 24:

```sh
node --experimental-strip-types tests/privacy.test.mjs
node --experimental-strip-types tests/eclipse-luminary.test.mjs
```

Тесты проверяют проекции контекста, сохранение расчётных данных, отсутствие содержимого в диагностике и обработку сбоев Langfuse. Спецификация: [plans/data-minimization.md](./plans/data-minimization.md).
